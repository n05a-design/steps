# Historischer Publikationsentwurf

Der Ordner enthält eine separate Auswahl für einen früheren Dokumentations- und Publikationsprozess.

| Einstieg | Inhalt |
| --- | --- |
| [Dokumentation](docs/) | Ausgewählte historische Projektunterlagen. |
| [Wissen](knowledge/) | Dokumentationsauswahl des damaligen Bestands. |
| [Aufträge](prompts/) | Kopierte Arbeitsaufträge dieses Pakets. |
| [Manifeste](manifests/) | Nachweise zum dokumentierten Paketstand. |
| [Builder](../tools/build_public_overlay.py) | Werkzeug für einen gesondert geprüften Neuaufbau. |

Aktuelle Änderungen im jeweiligen Quellordner des [Hauptbaums](../README.md) pflegen. Für eine Veröffentlichung die [Rechte- und Releasevorgaben](../docs/governance/README.md) anwenden.
