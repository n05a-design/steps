# Wissensprüfung und Referenzidentität

Hier liegen Referenzdaten, fachliche Korrekturen und datierte Prüfberichte. Der Master und die Integritätsregister gehören zur aktuellen Prüfkette.

| Einstieg | Inhalt |
| --- | --- |
| [Golden-Daten](golden_cases/README.md) | Kanonische Referenzfälle und ihr Testspiegel. |
| [Golden-Datenvertrag](GOLDEN_DATA_SOURCE_OF_TRUTH.md) | Herkunft, Identität und Pflege. |
| [Identitätsbaseline](REFERENCE_IDENTITY_BASELINE.json) | Geschützte Identitäten und Referenzhashes. |
| [Migrationsregister](REFERENCE_ID_MIGRATION_REGISTER.csv) | Dokumentierte Korrekturen und Zielhashes. |
| [Fehlerregister](MUSICAL_ERROR_REGISTER.csv) | Historische Befunde und Gegenbeispiele. |
| [Wissenslücken](MUSIC_KNOWLEDGE_GAPS.md) | Datierte Einordnung des Wissensbestands. |

Für den heutigen Prüfstand den [Benchmark](../benchmark/README.md) und die [Tests](../../tests/README.md) ausführen.
