# knowledge/concepts/progressions

Kadenz, Stufenanalyse, Reharmonisierung und Progressionsmuster.

Der [einzeln geprüfte App-Katalog](REVIEWED_PROGRESSIONS.md) wird mit
`python scripts/render_reviewed_progressions.py` aus
`src/steps/progression/reviewed_progressions.json` erzeugt. Die App verwendet
`app.knowledge` für denselben Bestand und dessen Lerntexte.

Neue Einträge brauchen einen konkreten fachlichen Gegencheck, eine Quellen-ID
aus `knowledge/sources/registry.yaml` und ein Prüfdatum. Der vollständige
historische Katalog bleibt unter
[CHORD_PROGRESSION_REFERENCE_LIBRARY.md](CHORD_PROGRESSION_REFERENCE_LIBRARY.md)
als Forschungs- und Kompatibilitätsbestand zugänglich.
