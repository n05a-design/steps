# Archivierung und Wiederherstellung

Die Manifeste halten Inventar, Pfadänderungen und Wiederherstellungsanweisungen für die Projektkonsolidierung fest.

| Einstieg | Inhalt |
| --- | --- |
| [Archivmanifest](ARCHIVE_MANIFEST.csv) | Originalpfad, Zielpfad und Nachweis. |
| [Archivierungsplan](ARCHIVE_PLAN.csv) | Datierte Einordnung der Maßnahmen. |
| [Wiederherstellung](ARCHIVE_RESTORE_GUIDE.md) | Prüf- und Rücksicherungsablauf. |
| [Aktionsprotokoll](ARCHIVE_ACTION_LOG.md) | Dokumentierte Archivschritte. |

Vor der Rückführung Quellstand und Hash prüfen und aktuelle Dateien am Zielpfad berücksichtigen.
