# Vorlagen für neue Einträge

Die Vorlagen helfen, Projektentscheidungen, Quellen, Fachclaims und Arbeitsaufträge nachvollziehbar zu erfassen.

| Einstieg | Inhalt |
| --- | --- |
| [Quelle](SOURCE_TEMPLATE.md) | Herkunft, Fundstelle und Rechte. |
| [Claim](CLAIM_TEMPLATE.md) | Aussage, Geltungsbereich und Gegenprobe. |
| [ADR](ADR_TEMPLATE.md) | Entscheidung, Alternativen und Folgen. |
| [Konflikt](CONFLICT_TEMPLATE.md) | Widerspruch und Belege. |
| [Funktionsspezifikation](FEATURE_SPEC_TEMPLATE.md) | Anforderungen und Abnahme. |
| [Glide-Reuse](GLIDE_REUSE_TEMPLATE.md) | Herkunft, Lizenz und Isolation. |
| [Rechercheauftrag](CRAWL_ORDER_TEMPLATE.md) | Fragestellung, Abruf und Nachweis. |
| [Übergabe](HANDOVER_TEMPLATE.md) | Stand, Änderungen und offene Punkte. |

Für operative Quellen- und Aufgabenpflege gelten die [Skill-Vorlagen](../.agents/skills/steps-knowledge-curation/templates/README.md).
