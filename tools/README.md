# Repository-Werkzeuge

Die [Strukturprüfung](validation/check_structure.py) prüft Pfade und JSON-Syntax. [Paket-Audit](verify_package_audit.py) und [Glide-Audit](audit/verify_glide_code_and_originals.py) dienen gesonderten Bestandsprüfungen. [Publikations-Overlay](build_public_overlay.py) und [sicheres Staging](safe_stage_steps_docs.py) sind Werkzeuge für separate Arbeitsabläufe. Die [Testanleitung](../tests/README.md) nennt die regulären Prüfungen für den heutigen Checkout.
