# Repository-Werkzeuge

Hier liegen Bestandsprüfung, Strukturprüfung und Werkzeuge für gesonderte Archivierungs- und Publikationsabläufe.

| Einstieg | Inhalt |
| --- | --- |
| [Validierung](validation/README.md) | Schneller Struktur- und JSON-Check. |
| [Audit](audit/README.md) | Glide-Quellstand und Originale abgleichen. |
| [Paketprüfung](verify_package_audit.py) | Historisches Auditpaket prüfen. |
| [Staging](safe_stage_steps_docs.py) | Separates Staging für Dokumentationspakete. |
| [Publikations-Overlay](build_public_overlay.py) | Historischer Builder für eine gesonderte Auswahl. |
| [Ingestion](ingestion/README.md) | Ablage und Verweis auf die aktiven Quellenwerkzeuge. |
| [Migration](migration/README.md) | Pfad- und Identitätsnachweise. |
| [Packaging](packaging/README.md) | Vorgesehene Paketwerkzeuge. |
| [Legacy](legacy/README.md) | Historische Bibliotheksgeneratoren. |

Die reguläre Prüfkette steht unter [scripts](../scripts/README.md) und [tests](../tests/README.md).
