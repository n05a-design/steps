# Architekturentscheidungen

Das Register hält Entscheidungen, Zuständigkeiten und offene Beschlüsse nachvollziehbar fest.

| Einstieg | Inhalt |
| --- | --- |
| [Entscheidungsregister](DECISION_REGISTER.md) | Beschlüsse, Status und Fundstellen. |
| [ADR-Vorlage](0000-ADR-template.md) | Ausgangslage, Entscheidung und Folgen. |
| [Architektur](../docs/architecture/README.md) | Technische Verträge und Einordnung. |

Angenommene Entscheidungen liegen als Einzeldateien `ADR-NNN-<thema>.md` neben dem Register (ADR-001, 003, 004, 006, 007, 013–017). Das Register führt alle IDs; `scripts/verify_reference_integrity.py` sperrt ihre Themen.

Bei einer neuen Entscheidung Begründung, Alternativen, Prüfbelege und Auswirkungen dokumentieren.
