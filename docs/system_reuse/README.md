# Wiederverwendung von Glide

Die [Glide-Unterlagen](GLIDE.md) beschreiben die technische Referenz und die Freigabebedingungen. Der [Implementierungsstand](../IMPLEMENTATION.md) dokumentiert die tatsächliche STEPS-Laufzeit.

| Einstieg | Zweck |
| --- | --- |
| [Glide-Referenz in diesem Repository](../../src/glide-v3.53/README.md) | Dokumentation des versionierten Ausgangsstands. |
| [Reuse-Matrix](../architecture/REUSE_AND_MIGRATION_MATRIX.md) | Eignung, Grenzen und Nachweisbedarf pro Bereich. |
| [Modulinventar](../../manifests/GLIDE_94_MODULE_REUSE_AUDIT_V2.csv) | Historische Zuordnungen für die Modulprüfung. |

Die lokale Glide-3.55.1-Dokumentation diente als Strukturvorbild für die
STEPS-Ordnerübersichten. Reuse-Entscheidungen beziehen sich auf die jeweils
dokumentierte Quellfassung.
