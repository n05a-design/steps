## MIDI endpoint decision brief

Keep ADR-007's file-export scope. The current single-source keyboard is the reference for production. For ADR-019, compare an endpoint-keyed reducer with an adapter that owns per-device state and emits a single merged display. The former makes per-channel sustain and identity visible to all consumers. The latter isolates driver lifetime but needs an explicit ordered merge. For either approach, key down state uses source/device/channel/note identity; a channel-mode message can affect only its endpoint. Focus loss clears the local keyboard source, disconnect clears the disconnected device, and global panic clears temporary notes everywhere. User selection remains separate. Define duplicate note policy, note-off with velocity zero, CC120/121/123 behavior, immutable event transfer between threads, stale-event generation IDs after disconnect and owners for cleanup. Device acceptance should include interleaved devices with the same note, independent pedals, blocked UI thread, unplug/replug and recovery without stuck notes.
