# Bestands- und Auditmanifeste

| Einstieg | Inhalt |
| --- | --- |
| [Indexnotizen](INDEX_NOTES.md) | Einordnung der Bestandslisten. |
| [Paket-Hashes](PACKAGE_FILES_SHA256.csv) | Dateiidentitäten eines Auditpakets. |
| [Quellen](EXTERNAL_PRIMARY_REFERENCES.csv) | Externe Referenzen des Audits. |
| [Anforderungen](REQUIREMENTS_TRACE_28.csv) | Zuordnung zu Prüf- und Arbeitsbereichen. |
| [Glide-Module](GLIDE_94_MODULE_REUSE_AUDIT_V2.csv) | Historischer Modulabgleich mit Reuse-Bewertung. |

Stand, Dateipfad, Prüfsumme und Prüfgrenze gemeinsam lesen. Archivverschiebungen stehen im [Archivmanifest](../archive/manifests/ARCHIVE_MANIFEST.csv).
